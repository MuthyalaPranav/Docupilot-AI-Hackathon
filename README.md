# DocuPilot AI

AI-assisted docstring and code-comment generator for Python, JavaScript, TypeScript, Java, C, C++, C#, Go, PHP, Ruby, Swift, Kotlin, Rust, and SQL.

## Features
- Multi-language AST, Esprima, and structural parsing before LLM generation
- OpenAI Responses API
- Review/edit/approve workflow
- Approved patch preview and downloadable updated source
- Syntax/style verification
- SQLite audit history
- Mock mode when OPENAI_API_KEY is not configured (clearly labelled)

## Requirements
- Python 3.11+
- Node.js 20+
- OpenAI API key (optional for mock mode; API usage may incur cost)

## Run locally

### Backend (PowerShell)
```powershell
cd backend
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
Copy-Item .env.example .env
# Edit .env and add OPENAI_API_KEY if you want real generation
uvicorn app.main:app --reload --port 8000
```
If PowerShell blocks activation, use:
```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m uvicorn app.main:app --reload --port 8000
```

### Frontend (new terminal)
```powershell
cd frontend
npm install
npm run dev
```
Open the URL Vite prints, usually http://localhost:5173.

## Test
Backend:
```powershell
cd backend
.\.venv\Scripts\python.exe -m pytest -q
```
Manual workflow:
1. Paste Python or JavaScript code.
2. Click Analyze & Generate.
3. Review or edit the suggestion.
4. Click Approve & Verify.
5. Download the resulting code and inspect the evidence/history panel.

## Environment variables
Backend `.env`:
- `OPENAI_API_KEY`: your secret API key; never put it in frontend code or commit it
- `OPENAI_MODEL`: defaults to `gpt-4.1-mini`
- `FRONTEND_ORIGIN`: defaults to `http://localhost:5173`
- `DATABASE_PATH`: defaults to `./docupilot.db`

## Deployment
Deploy backend as a Render Web Service:
- Root directory: `backend`
- Build command: `pip install -r requirements.txt`
- Start command: `uvicorn app.main:app --host 0.0.0.0 --port $PORT`
- Set `OPENAI_API_KEY`, `OPENAI_MODEL`, `FRONTEND_ORIGIN`, and optionally `DATABASE_PATH` in environment variables.
- For durable SQLite history, attach a persistent disk and set `DATABASE_PATH` to a path on that disk; otherwise history may be lost on redeploy.

Deploy frontend as a Vercel project:
- Root directory: `frontend`
- Framework: Vite
- Environment variable `VITE_API_URL`: your deployed backend base URL, without trailing slash.
- Redeploy after setting the variable.

For a quick local demo, the app works without an API key in clearly marked MOCK MODE. Do not claim mock output was generated by a live model.
